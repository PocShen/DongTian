# 洞天 - 网络空间测绘聚合工具

**洞天** 是一款面向网络空间测绘、安全研究、资产梳理与攻击面分析场景的多平台聚合查询工具。  
它将多个主流网络空间测绘平台统一到同一界面中，支持通用语法输入、多平台适配查询、结果聚合展示、详情查看、数量统计与数据导出。

**一条语法，多端通查。**  
**公众号：教练说安全**

---

## 工具简介

在日常测绘工作中，最耗费时间的往往不是“不会查”，而是：

- 同一条语法需要在多个平台重复改写
- 不同平台字段名和查询方式不一致
- 查询结果需要来回切换、反复比对
- 资产信息需要手动整理和导出
- 平台之间的数据互补需要人工完成

**洞天** 的目标不是替代某一个平台，而是作为一个统一入口，尽可能把这些分散的流程整合起来。

它希望解决的是一个非常实际的问题：

> **让网络空间测绘从“多个平台分别操作”，变成“统一入口集中查询”。**

---

## 名称寓意

**洞天**，取“洞察天地”之意。

- **洞**：有洞若观火、洞察秋毫之意  
  代表对网络资产、服务特征、暴露面与空间分布的精准识别能力

- **天**：有广阔空间、全局视野之意  
  象征网络空间的辽阔复杂，也代表更高维度的观察与认知

所以，“洞天”所表达的是：

> **洞若观火，察网络之微；放眼天地，见空间之广。**

这也正是本工具的核心定位：  
不仅是“查到结果”，更是帮助使用者建立更统一、更高效、更具全局感的网络空间认知能力。

---

## 特色亮点

### 多平台聚合查询
支持多个网络空间测绘平台统一查询，减少平台切换和重复操作。

### 通用语法适配
输入一条常见查询语法，工具会尽量自动适配为对应平台可执行的查询方式，降低跨平台使用门槛。

### 统一结果展示
不同平台返回的数据会统一汇总到同一结果表中，方便对比、筛选和快速定位。

### 平台级数量统计
支持查看各平台当前已加载条数与结果总量，便于判断数据规模和后续翻页价值。

### 查询详情查看
支持查看单条资产的详细字段信息，包括：

- IP
- HOST
- 端口
- 协议
- 标题
- 证书
- 备案
- 城市
- 更新时间
- 来源平台

### 常用语法速查
内置常用语法表，可在日常使用中快速参考。

### 辅助能力集成
当前已集成：

- IconHash
- 证书转换

便于在实际测绘场景中联动使用。

### 数据导出
支持导出为：

- CSV
- JSON
- Excel

方便后续整理、归档、分析与报告编写。

### 凭证默认留空
工具默认不附带任何个人 API Key，分发和使用更加安全。

## 工具优势

洞天 的优势，不在于单纯叠加平台数量，而在于尽可能把多平台查询这件事做得更统一、更顺手、更适合日常使用。

它更关注以下几个核心问题：

- 查询语法是否尽量统一
- 平台结果是否便于集中查看
- 数量统计是否足够直观
- 结果导出是否足够方便
- 整体交互是否适合长期使用

换句话说，它不是为了“展示功能”，而是为了真正解决多平台测绘过程中重复、割裂和低效的问题。
